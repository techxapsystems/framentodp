# Padrão de Layout para PDF de Advertência Disciplinar

## Estrutura do Documento

### Cabeçalho
- **Título**: "Advertência Disciplinar" (centralizado, negrito)

### Seção de Dados da Empresa e Funcionário
Formato de duas colunas com labels e valores:

```
Empresa:    TRANSPORTESFRAMENTOLTDA
            Contorno da Petrobras, 107
            32.669-500 - BETIM                    MG
CNPJ        00.766.315/0009-00

Empregado:  ALESSANDRO MIGUEL DA SILVA
CPF         101.387.966-02
CTPS        001013879         6602
```

### Corpo do Documento
- Parágrafo introdutório explicando o motivo da advertência
- Texto justificativo detalhado com:
  - Data do fato
  - Descrição do ocorrido
  - Consequências
  - Referências a normas/políticas
  - Avisos formais sobre responsabilidades

### Rodapé
- Observação final
- Data e local (ex: "BETIM, 23 de Março de 2026.")
- Duas linhas de assinatura:
  - Esquerda: Empresa
  - Direita: Funcionário

### Rodapé da Página
- Identificação do documento (ex: "FPD0131.COL")
- Data/Hora de impressão
- Nome da empresa

## Estilos
- Fonte: Padrão (sem serif)
- Tamanho: 11pt para corpo, 12pt para título
- Margens: ~40px
- Espaçamento entre seções: ~20px

## Campos Dinâmicos
- Nome da empresa
- CNPJ
- Nome do funcionário
- CPF
- CTPS
- Matrícula
- Data do fato
- Descrição do ocorrido
- Data da advertência
- Local da advertência
